## 이 세션에서 확정한 것

1. **리포트 섀시 v1 — 기업·산업 공용 9슬롯**: 판결 헤더 → Key Data → 요약 지표 → 핵심 판정(밸류에이션/시장 전망) → 구조 분석 → 비교 테이블(같은 스키마로 산업↔기업 드릴다운) → 핵심 논점 → 리스크·트리거 → 결론·부록.
2. **콘텐츠 원칙**: 1페이지 = 판결문(결론 먼저), 가정 전면 공개(기준이익·배수·미적용 조정), 점 추정 금지(범위·시나리오·민감도), 논점은 "통념 vs 데이터 vs 판별 지표" 3단, 신용평가식 상향/하향 트리거, 모든 표·차트에 출처·기준일 스탬프.
3. **PRD v0.4 정합**: 층위 표기(AI 평가 리포트 = 2층 Decision-ready, 공인회계사 개별 검토 미포함 명기), FR-4.6 고정 문법(`방법론 · 공인회계사 설계 / 작성 · AI / 인증 · 별도 수임`), 확정 평가 전환 CTA(FR-5).
4. **디자인 시스템**: 딥서치 브랜드 토큰 그대로 — 무채색 + Signal 블루 `#0c74ee` 1색(페이지당 1–2곳), 프리텐다드 단일 서체(표 숫자는 `font-variant-numeric: tabular-nums`), 경계는 그림자 없이 헤어라인 `rgba(20,24,30,.14)/.08`, 8px 간격, A4 = 794×1123px(@96dpi), 인쇄는 `@page 210mm 297mm; margin 0` + 좌우 여백 14.8mm.
5. **표본 데이터 정책**: 고려공업검사 감사보고서 실수치만 사용, 미확보 데이터(피어 재무)는 "Finorma 조회 연동" 슬롯으로 비움. 파생 수치는 산술 검증 완료(민감도 셀, 시나리오 범위, 성장률 등).

## 미결 사항 (원래 채팅에서 결정할 것)

- **디렉션 선택**: 캔버스 "디렉션 탐색" 페이지의 3안 — A 빅 넘버 버딕트 / B 절제된 벤토 / C 미드나이트(스트레치, 디지털 표지 한정) — 중 선택 또는 혼합. 현행 리포트 v1은 스위스 컬럼 계열.
- 선택한 디렉션으로 나머지 4개 페이지 리디자인 여부.
- 산업 리포트 실물 표본 제작 (섀시 슬롯 스왑).
- 실제 에이전트(value-agent) 리포트 생성 코드에 이 템플릿을 이식하는 방법.

## 집에서 준비하면 좋은 것 (이 세션이 만들 수 없는 것들)

1. **실제 에이전트의 현재 리포트 템플릿 코드** — value-agent 저장소의 리포트 생성/렌더링 부분 접근 권한 또는 파일. 이게 있어야 "시안"이 아니라 "이식"이 됩니다. (이 세션의 GitHub 연결에는 deepsearch-hq org가 없었음)
2. **디렉션 결정** — 캔버스 2페이지 3안을 보고 A/B/C 또는 혼합 지시.
3. **레퍼런스 핀 스크린샷** — 핀터레스트에서 마음에 든 톤 2~3장. 말보다 정확합니다.
4. **원래 채팅의 결정사항** — 이전에 이미 정한 방향·거부한 시안이 있으면 위 컨텍스트 블록에 한두 줄 추가.
