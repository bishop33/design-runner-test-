# 리서치 브리프 ① — 잘 만든 밸류에이션·산업 리포트의 콘텐츠 구조

조사 대상: 셀사이드 리서치(CFA 기준서, Morgan Stanley Risk-Reward, 한국 증권사 관행), 409A/공정가치 평가보고서, VC 투자심의 메모(Bessemer), 산업 리포트(CB Insights·Statista·McKinsey·삼정KPMG), 신용평가 리포트(Moody's·한신평), Minto 피라미드/BLUF.

## 정석 섹션 아키텍처 (핵심 원리: 1p=판결문, 본문=증거, 부록=계산)

0. **표지/헤더 밴드**: 3초 안에 "무엇을, 얼마로, 왜". 결론 담긴 문장형 헤드라인 + 적정가치 범위 + 괴리율 + 기준일.
1. **Key Data 박스** (1p 사이드 레일): 시총(비상장은 최근 라운드), 주주, 거래 데이터.
2. **요약 지표 테이블**: 3+2개년(실적+추정E), 매출·OI·OPM·순이익·PER·PBR·EV/EBITDA·ROE.
3. **투자 요약**: BLUF — 결론→근거 3개(숫자 박힌 액션 타이틀)→리스크 1줄→Key Debates(시장 통념과 어디가 다른가).
4. **밸류에이션 (앞쪽 배치)**: 풋볼필드(방법론별 범위+수렴 구간이 결론), 방법론별 가정 테이블(WACC 구성·성장률·배수·가중치·DLOM 전부 공개), 민감도 매트릭스(WACC×g), Bull/Base/Bear+스큐.
5. **사업/비즈니스 모델 (압축)**: 회사 소개가 아니라 매출 방정식(P×Q) 중심.
6. **산업·경쟁**: TAM/SAM/SOM 산출 로직 명시, 시장 성장 vs 회사 성장 분리.
7. **재무 분석 & 피어 비교**: 절대값이 아닌 상대 위치. 피어 테이블(평균·중앙값 행, 대상 하이라이트, 선정 기준 각주).
8. **투자포인트 (Key Debates)**: 주장+근거 데이터+밸류에이션 연결("이게 맞으면 가치 X%").
9. **리스크 & 모니터링**: 리스크→정량 영향→완화 요인→감시 지표 + 상향/하향 트리거(신용평가식 — 에이전트 자동 갱신과 궁합 최고).
10. **결론 & 부록**: 결론 재확인(새 정보 금지) + 전체 재무제표·DCF 스케줄·출처·기준일 목록·면책.

## 훌륭함과 평범함을 가르는 14요소

1p 원라인 판결 / 풋볼필드 / 명시적 가정 테이블 / 3-시나리오+스큐 / 민감도 매트릭스 / 피어 테이블 관례 / Key Debates 프레이밍 / 상향·하향 트리거 / 모든 숫자에 출처·기준일 / 액션 타이틀(제목이 결론) / 추정 vs 실적 vs 컨센서스 구분(E 표기) / 리스크마다 완화 요인+정량 영향 / what-would-have-to-be-true 역산 / 밸류에이션↔투자포인트 연결.

## 인사이트 패턴 (데이터→통찰)

피어 대비 편차 / 추세 변곡점 / 정상화 이익(사이클 정점 외삽 금지) / 분해(P×Q, 듀폰) / 배수-펀더멘털 회귀(할인이 정당한가) / 내재 가정 역산 / 컨센서스 델타 / 시장 성장 vs 점유율 / 선행지표 체인 / 시나리오 폭·스큐로 확신 표현.

## 기업↔산업 공용 섀시 9슬롯

| # | 슬롯 | 기업 | 산업 |
|---|---|---|---|
| 1 | 판결 헤더 | 적정가치 범위+괴리율 | 전망 판정+시장규모·CAGR |
| 2 | Key Data | 시총·주주·거래 | 규모·기업수·집중도(CR3)·평균 마진 |
| 3 | 요약 지표 | 3+2개년 재무 | 규모·성장률 5개년 세그먼트별 |
| 4 | 핵심 판정 | 밸류에이션(풋볼필드·시나리오·민감도) | 시장 전망(같은 엔진 재사용) |
| 5 | 구조 분석 | 비즈니스 모델·매출 방정식 | 밸류체인·수익 풀 |
| 6 | 비교 테이블 | 피어 비교 | 플레이어 맵 — **같은 스키마**(드릴다운 연결) |
| 7 | 논점 | Key Debates 3단 | 트렌드·구조 변화 같은 포맷 |
| 8 | 리스크·트리거 | 기업 리스크+완화+트리거 | 규제·수급·기술 대체+모니터링 |
| 9 | 결론·부록 | 동일 | 동일 |
