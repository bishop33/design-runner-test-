# 리서치 브리프 ② — 리포트 편집 디자인 톤앤매너 + 2025–26 트렌드

조사: Dribbble/Behance/Pinterest 인덱스(직접 접속은 네트워크 차단이라 검색 기반 교차 검증), Datawrapper·FT·Economist 데이터비주얼 가이드, McKinsey/Stripe/토스 스타일 분석, 2025–26 애뉴얼리포트 트렌드 소스 다수.

## 채택 아트 디렉션

**스위스/기관 그리드 베이스 + 빅넘버·KPI 타일 이식.** 딥서치 브랜드 토큰(무채색+Signal 블루 1색, Pretendard, 헤어라인, 8px)과 정확히 합치 — "제약을 지키는 게 곧 트렌드"가 리서치의 핵심 결론.

## 레이아웃 규율

- A4, 12컬럼, 본문 크기에서 베이스라인 역산. 우측 사이드 레일(셀사이드 1p 관행: 의견·목표가·Key Data 고정).
- 섹션 헤더: 넘버링+상단 룰 1개, 박스 금지. KPI 스탯타일 행(라벨→큰 숫자→비교값).
- 그룹핑 1차 수단 = 여백, 2차 = 헤어라인, 박스는 최후. 그림자 금지.
- 결론(볼드 문장) vs 근거(차트/표) 분리 — 맥킨지 액션 타이틀. 페이지당 빅넘버 1개.
- 모든 차트·표 아래 소스라인("자료: ○○, 기준일") 8~9px.

## 데이터 시각화

- 시리즈 기본 = 다크 톤 1색, 주인공만 액센트, 비교군 회색 (FT/Economist 방식).
- 풋볼필드: 수평 플로팅 바, 수렴 구간을 옅은 액센트 밴드로 강조 — 겹침이 결론.
- 민감도: 레드-그린 대신 단색 농도 스케일, 베이스 셀 굵은 보더.
- 표: 세로 룰 금지·수평 룰만, 숫자 우측 정렬+tabular figures, 컬럼별 소수 자릿수 고정.
- 이중축 금지. 범례보다 직접 라벨.

## 2025–26 트렌드 6 (핀터레스트·비핸스 기준)

1. **스위스 그리드 리바이벌** — 신뢰가 상품인 금융 문서의 원형.
2. **빅 넘버/오버사이즈 뉴머럴** — FTSE 상장사 관행. 결론이 숫자인 밸류에이션과 동형. 썸네일에서도 읽힘.
3. **벤토 그리드(절제 버전)** — 셀 크기=정보 중요도. 컬러 카드 대신 탑 룰로 절제하면 브랜드 규칙과 공존.
4. **에디토리얼 미니멀리즘** — 키커·풀쿼트·결론형 차트 제목. 독립 스타일보다 양념으로 이식.
5. **모노크롬+단일 액센트** — "색은 장식이 아니라 강조·긴장의 표시". #0c74ee 제약과 일치.
6. **미드나이트/다크 커버** — 핀테크 임원 보고 미학. 표지·디지털 배포 한정(A4 인쇄 부적합, 브랜드 밝은 지면 규칙 위반 — 스트레치).

## 피할 것

네오브루탈리즘(신뢰와 충돌) / 글래스모피즘·질감(그라데이션 의존) / 맥시멀리즘 / 장식성 3D·일러스트 히어로 / 파스텔 다색 인포그래픽 / 풀블리드 스톡사진 커버 / proportional figures로 숫자 표 조판 / 저대비 회색 본문 / 페이지마다 다른 차트 스타일.
